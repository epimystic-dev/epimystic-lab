# nbshape demonstration inputs

`healthy_notebook.ipynb` has nothing for nbshape to report: strictly
increasing execution counters, outputs that match their own counters,
a seeded sampler, relative paths, coherent kernel metadata, and a cell
id on every cell. It exits 0.

`weak_notebook.ipynb` collects many of the shapes at once and exits 2.
Neither file is a real notebook from a real project, and no string in
either one is a real credential.
