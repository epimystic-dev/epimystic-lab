### `renovatelint` -- static linter for Renovate bot config files

Three independent 2026-10 signals converged on the same surface -
**the Renovate config file in a repository**, the artifact that
governs when and how dependency updates auto-merge - and together
establish a current unmet need the lab's hygiene-linter family can
serve directly.

1. **The LiteLLM supply-chain attack (2026-10-21).** On
   2026-10-21, attackers used stolen GitHub CLI OAuth tokens
   (traced to an unrevoked master key exposed publicly 2026-05-27)
   to push a trojanized LiteLLM 1.107.0 wheel through the official
   PyPI release pipeline and planted poisoned Docker Hub tags. The
   wheels were live on PyPI from 11:39 to 13:23 UTC (~104 minutes);
   Docker Hub tags remained affected until 14:20 UTC. The tampered
   package carried an info-stealer that harvested AWS / Azure / GCP /
   Kubernetes credentials, AI provider secrets, developer keys,
   browser data, and environment variables; roughly 49,000 downloads
   of 1.107.0 are estimated, with AWS credential-validation calls
   observed on the same day. (Help Net Security 2026-10-22, Socket
   2026-10, SOCRadar 2026-10, Aviatrix 2026-10, Malware News
   2026-10, neoteo.com 2026-10.)
2. **The 2026 Renovate "security mode" community posture
   (consolidating across the year).** Compass Security (2025-05
   "Renovate - keeping your updates secure"), safeguard.sh ("Renovate
   2026 Security Mode Field Test", "Renovate Bot Configuration
   Recipes for 2026"), and systemshardening.com ("Renovate and
   Dependabot Security Configuration") converge on the shape
   family: `minimumReleaseAge: 14 days` as the quarantine window
   that catches most malicious releases before auto-merge;
   `osvVulnerabilityAlerts: true` and
   `:enableVulnerabilityAlertsWithLabel("security")` as the
   security-mode preset; packageRules scoped by `matchUpdateTypes`
   to safe subsets (patch / pin / digest / lockFileMaintenance);
   `extends` pins where the preset is sourced from a repo.
3. **Open Source Supply Chain Attacks by Ecosystem, 2025 to 2026
   (safeguard.sh).** Industry-side analysis that frames the shape
   family across both npm and PyPI incident waves and names the
   dependency-bot config as a per-repo defensive surface.

Renovate is reported as covering 90+ package managers in 2026
(AppSec Santa Renovate Review 2026); its config file is the per-repo
developer-facing artifact a Renovate run reads. Every finding class
the week's news coverage named has a direct renovate.json-side
shape: enabled:false stealth-off (RNV-001), root automerge:true
without quarantine (RNV-002), unpinned repo preset (RNV-003),
credential-shaped literal (RNV-004), fetch-and-exec in
allowedPostUpgradeCommands (RNV-005), hidden-character class
(RNV-006), unscoped packageRules automerge (RNV-007),
vulnerabilityAlerts disabled (RNV-008), execution surface present
(RNV-009), quarantine below the 7-day floor (RNV-010); plus two INFO
rules on missing `$schema` (RNV-011) and missing `timezone`
(RNV-012).

`renovatelint` is the small offline pre-flight that catches the
twelve shape defects *before* Renovate acts on the config. 5 HIGH / 5
MEDIUM / 2 INFO. 138 tests pass under `python -m unittest discover
-s tests`; every rule has positive-and-negative discrimination; the
shared package-surface contract against `docs/CONVENTIONS.md` is
locked; the cp1252-console reporter invariant is locked by a
subprocess test. Independent implementation, not affiliated with or
endorsed by Mend / Renovate, the Renovate maintainer community, or
any of the cited security publications.
