## What we chose to build, and why

**One artifact this week**, following the standing "quality over quantity"
bar: one world-class primitive beats three mediocre ones. The batch contains
`agentmdlint` and nothing else.

**`agentmdlint`** -- offline maintainability linter for agent instruction
files. Zero-dep Python (stdlib only), MIT. Direct response to the frontier
signal at [1] below: arXiv 2608.11095 ("CLAUDE.md Growth", 2026-08-11)
characterises 247,694 instruction lifetimes across 1,867 repositories and
shows that agent instruction files grow +226% over their lifetime with +4.9
net instructions per commit, gaining a log-hazard of -0.032/commit against
deletion. The paper names the phenomenon "catastrophic remembering" and
proposes rationale comments as the remedy. `agentmdlint` is the small
pre-flight primitive that operationalizes that measurement: given a
repository checkout, it scans a canonical set of instruction-file locations
(`AGENTS.md`, `AGENT.md`, `CLAUDE.md`, `GEMINI.md`, `CURSOR.md`,
`AI_INSTRUCTIONS.md`, `.cursorrules`, `.github/copilot-instructions.md`,
etc.) and emits a structured verdict (`healthy` | `needs-attention` |
`unhealthy` | `unknown`) with a JSON report, in a form that runs as a CLI,
a pre-commit hook, or a CI check.

Ten documented rules: byte-size bloat (AGENTMD-001), instruction-count bloat
(AGENTMD-002), near-duplicate instructions (AGENTMD-003), missing rationale
(AGENTMD-004), dead heading (AGENTMD-005), drift markers
(TODO/FIXME/XXX/HACK/TBD/DEPRECATED) (AGENTMD-006), stale amendment date
(AGENTMD-007), candidate contradiction (AGENTMD-008), missing purpose header
(AGENTMD-009), and imperative-wall (AGENTMD-010). 118 tests: 20 parser tests
(headings / sections / code-fence awareness / imperative and rationale
detection incl. case-insensitivity and word-boundary correctness / drift
markers / jaccard / polarity / subject normalisation / BOM strip), 30 rule
tests (per-rule positive-and-negative + registry coverage assertion + soft
vs hard severity + threshold respect + composite evaluation), 20 scanner
tests (discovery incl. case-insensitive + nested copilot-instructions +
custom-files override + max-files cap + deterministic ordering; read incl.
UTF-8 + BOM + latin-1 fallback + max-bytes truncation + missing file), 14
verdict-and-report tests (healthy / needs-attention / unhealthy / unknown /
strict escalation / high-overrides-medium / JSON determinism + parseability
+ info visibility), 12 CLI tests (version / missing-path stderr / no-files
default+strict / unhealthy exit / JSON output / single file / info toggle /
custom files / invalid --today / default cwd), and 8 end-to-end fixture
tests (healthy / bloated / duplicates / contradictions / stale / unknown --
one fixture per verdict class plus JSON round-trip determinism).

The lab's hygiene-linter family already covers file-contents hygiene
(`envcheck`, `jsonlcheck`, `jwtcheck`), eval-stream hygiene (`jsonldiff`,
`jsonlsample`), install-manifest hygiene (`reqcheck`), license-chain hygiene
(`licensechain`), contribution-policy hygiene (`aicontribcheck`), and
agent-skill *safety* hygiene (`skillcheck`). `agentmdlint` extends the
family to agent-instruction *maintainability* hygiene -- the orthogonal
question to `skillcheck`'s "safe to load?", answered as "still maintained?".
Both scan the same file surface but for orthogonal concerns; they compose
naturally as a two-stage pre-flight.

Secondary candidates considered this cycle: `patchbloat` measurement
primitive from arXiv 2608.13292 (RECAP -- patches 121.78% larger than
developer patches; deferred because a small-scale primitive would need a git
integration that pushes past the zero-dep line and the paper's measurement
methodology is the main asset, not the intervention), and `cursorruleslint`
targeted at .cursorrules specifically motivated by arXiv 2608.10622
(subsumed into `agentmdlint` via the `--files` override). Deferred
candidates from prior weeks remain on standing watch.

## Signal we noted (not built this week)

1. **CLAUDE.md Growth ("catastrophic remembering")** (arXiv 2608.11095,
   2026-08-11). Characterises 247,694 instruction lifetimes in 1,867
   repositories; agent instruction files grow +226% over lifetime with +4.9
   net instructions per commit and a log-hazard of -0.032/commit against
   deletion. Names the phenomenon "catastrophic remembering" -- the inverse
   of catastrophic forgetting -- and proposes rationale comments as the
   remedy. The paper's *framing* is the direct motivation for
   `agentmdlint`; the paper's methodology, benchmark, and any reference
   code was NOT consulted.
   [arXiv](https://arxiv.org/abs/2608.11095)

2. **RECAP: Post-Generation Refinement Adapter for Patch Verbosity**
   (arXiv 2608.13292, 2026-08-13). Coding agents produce patches 121.78%
   larger than developer patches; proposes a post-generation refinement
   adapter. Signals the "patch-bloat measurement" surface as a candidate
   primitive (deferred; needs a git-diff integration that would push
   past the current zero-dep line).
   [arXiv](https://arxiv.org/abs/2608.13292)

3. **GitSkills: 3.8M SKILL.md files** (arXiv 2608.10906, 2026-08-11).
   Dataset of 3.8M SKILL.md files from GitHub showing agent skill adoption
   and maintenance patterns. Reinforces the `skillcheck` direction and
   provides empirical scale for the assumption that skill inventories are
   now a large-N surface.
   [arXiv](https://arxiv.org/abs/2608.10906)

4. **Cursorrules Empirical Study** (arXiv 2608.10622, 2026-08-11). Analysis
   of 12,110 `.cursorrules` configuration files across GitHub repositories;
   catalogues adoption patterns. `agentmdlint` already targets
   `.cursorrules` via the default-files list, so no separate primitive was
   built.
   [arXiv](https://arxiv.org/abs/2608.10622)

5. **Personalized Skills vs Generic Skills** (arXiv 2608.10319, 2026-08-10).
   Framework extracting reusable developer preferences; finds generic
   skills outperform developer-specific personalization on downstream
   metrics. Suggests the maintenance model for `agentmdlint`-style
   instruction files should favour cross-repo generic guidance over
   per-repo idiosyncrasy -- a design constraint, not a buildable primitive.
   [arXiv](https://arxiv.org/abs/2608.10319)

6. **Agentic Configuration Management (ACM)** (arXiv 2608.11166,
   2026-08-11). Framework-independent governance model for versioning
   heterogeneous agentic system configurations. Signals a `agentcfglint`
   primitive on the configuration-file surface (deferred; the
   governance-model shape is heavier than a small primitive).
   [arXiv](https://arxiv.org/abs/2608.11166)

7. **Tool Architecture Study** (arXiv 2608.11386, 2026-08-11). Demonstrates
   how tool architecture shapes agent behavior; Python CodeAct interfaces
   reduce token usage by 56.3%. Observational, not directly buildable as a
   small primitive without a runtime harness.
   [arXiv](https://arxiv.org/abs/2608.11386)

8. **Self-Evolution Harnesses** (arXiv 2608.10178, 2026-08-10). Shows
   evolved harnesses encode language-ecosystem machinery that resists
   universal transfer. Signals cross-language transfer as a persistently
   unmet capability but not a small-primitive shape.
   [arXiv](https://arxiv.org/abs/2608.10178)

9. **SpecPath: Specification-Path Sensitivity** (arXiv 2608.09799,
   2026-08-10). 35% of successful specifications fail on equivalent
   histories -- exposes ordering-sensitivity in coding agents. Signals a
   "spec-path canonicaliser" primitive (deferred; needs a target-framework
   spec surface).
   [arXiv](https://arxiv.org/abs/2608.09799)

10. **RETRACE: Training-Free Post-Generation Verification** (arXiv
    2608.08950, 2026-08-09). Bidirectional reconstruction for patch
    validation. Interesting verification-surface primitive but requires a
    diff-reasoning harness, not a stdlib primitive.
    [arXiv](https://arxiv.org/abs/2608.08950)
