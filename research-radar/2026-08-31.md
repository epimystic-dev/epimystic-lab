## What we chose to build, and why

**One artifact this week**, holding the standing quality-over-quantity bar.
The batch contains `elevatescan` and nothing else.

**`elevatescan`** -- offline static scanner for
**instruction-privilege-escalation shapes** in files an agent will consume
as low-privilege observations, tool outputs, user-provided files, or ingested
pages. Zero-dep Python stdlib, MIT. Direct response to a three-paper
convergence this week on the same failure mode:

1. arXiv 2608.27299 ("When Context Gets Root: Privilege Escalation in LLM
   Harnesses", 2026-08-27) names *instruction privilege escalation* as a
   distinct attack class: agent harnesses construct context per invocation,
   and that construction elevates low-level content to a higher
   instruction level than its origin. Measured: 13 attack objectives
   achieved across all six evaluated coding-agent harnesses under
   unrestricted execution; all 13 also achieved against the three harnesses
   that offer automatic permission review.
2. arXiv 2608.27146 ("When Tool Outputs Become Commands", 2026-08-27)
   frames the same failure at the tool-output surface: untrusted runtime
   observations that specify concrete actions become "commands" that drive
   real-world side effects beyond user intent. SARA limits attack-success-
   rate to <=0.63% by separating action induction from execution
   authorization -- but the pre-flight problem remains: what should never
   have entered the observation stream in the first place?
3. arXiv 2608.28411 ("LongPIBench: A Long-Context Benchmark for Prompt
   Injection", 2026-08-28) shows even simple heuristic injection shapes
   achieve high success rates on long-context inputs across 4 realistic
   application scenarios (paper peer review, resume screening, code review,
   email summary) and "frequently bypass state-of-the-art defenses".

The convergence is important: three independent groups this week measure the
same failure mode at three different layers of the same stack (harness
construction, tool-output surface, long-context ingestion). `elevatescan`
is the pre-flight offline scan -- what a lint step for content-that-will-be-
ingested should do before it hits the harness template.

Ten documented rules: fake role-marker injection (ESC-001, HIGH), override-
directive smuggling (ESC-002, HIGH), persistent-goal / long-term-memory
smuggling (ESC-003, HIGH), scheduled-task / cron hijack (ESC-004, HIGH),
elevated-authority claim (ESC-005, HIGH), tool-output-marker followed by
imperative directive (ESC-006, MEDIUM), URL with instruction-shaped query
or fragment parameter (ESC-007, MEDIUM), hidden-content marker (HTML comment
with instruction words, or zero-width chars) (ESC-008, MEDIUM), code fence
labelled with role/instruction language (ESC-009, MEDIUM), bare
sentinel-token exposure in prose (ESC-010, INFO).

167 tests: 7 types tests (Severity/Verdict enums + Finding immutability +
sort-key ordering), 10 parser-helper tests (_line_col across LF/CRLF, _short
truncation and newline-flatten), 6 rule-registry invariants (count == 10 +
id uniqueness + canonical ESC-NNN + non-empty descriptions + severity split
5/4/1 HIGH/MEDIUM/INFO + all check-fns callable), per-rule positive+negative
across all ten rules with adversarial-word-vs-ordinary-word negatives (11
tests for ESC-001, 8 for ESC-002, 8 for ESC-003, 8 for ESC-004, 8 for
ESC-005, 6 for ESC-006 including direction check, 5 for ESC-007, 5 for
ESC-008 including zero-width detection, 5 for ESC-009, 5 for ESC-010
including the "sentinel inside role-marker window is silenced" invariant,
plus a healthy-prose-fires-nothing surface check), 24 scanner tests
(strip_bom / read_text utf-8/BOM/latin-1/max-bytes + discover missing-path /
single-file glob-match / single-file glob-miss / dir traversal / case-
insensitive glob / max-files cap / deterministic sort / custom-glob extend /
yaml variants + scan_path healthy / override-fires-esc002 / read-errors-do-
not-crash / findings-sorted / disable-suppresses / max-files-bound /
empty-dir), 20 verdict-and-report tests (rollup no-files-unknown + high-
unhealthy + medium-needs-attention + high-beats-medium + info-default-
healthy + info-strict-needs-attention + no-findings-healthy + exit-codes
2/1/1/2/0 + text-verdict-line + text-totals + text-hides-info-by-default +
text-shows-info-with-include-info + text-lists-errors + JSON-parseable-
deterministic + JSON-omits-info-by-default + JSON-includes-info-when-
configured + JSON-errors-field), 13 CLI tests (--version + --list-rules +
missing-path-stderr-exit-2 + healthy-dir-exit-0 + unhealthy-dir-exit-2 +
no-files-default-exit-1 + no-files-strict-exit-2 + --json-parseable +
--include-info + --disable + --max-files-0 + --max-bytes-0 + default-path-
is-cwd + --glob-extends), and 15 end-to-end fixture tests across the ten
adversarial fixture shapes (healthy / override / role_marker /
persistent_goal / scheduled_task / elevated_authority / tool_output /
url_smuggle / hidden_marker / code_fence / unknown) with JSON-roundtrip-
determinism verification and cross-fixture sort-order invariant.

Dogfood: running `elevatescan examples/malicious_notes.md` yields
verdict=unhealthy, exit 2, 6 HIGH findings across ESC-001 (x2), ESC-002,
ESC-003, ESC-004, ESC-005 -- proof that the primitive fires cleanly against
a document that stitches every attack shape into one adversarial file. Same
tool on `examples/healthy_notes.md` yields verdict=healthy, exit 0, zero
findings.

The lab's hygiene-linter family already covers file-contents hygiene
(`envcheck`, `jsonlcheck`, `jwtcheck`), eval-stream hygiene (`jsonldiff`,
`jsonlsample`), install-manifest hygiene (`reqcheck`), license-chain
hygiene (`licensechain`), contribution-policy hygiene (`aicontribcheck`),
agent-skill safety hygiene (`skillcheck`), agent-instruction maintainability
hygiene (`agentmdlint`), and test-oracle-shape hygiene (`oraclecheck`).
`elevatescan` adds the **agent-consumed content** layer: the orthogonal
question to skillcheck's "safe to load?", agentmdlint's "still maintained?",
and oraclecheck's "does the test have any chance?" is "safe for the agent
to ingest at low privilege?".

## Signal we noted (not built this week)

1. **When Context Gets Root: Privilege Escalation in LLM Harnesses** (arXiv
   2608.27299, 2026-08-27). Names *instruction privilege escalation* as an
   attack class where agent harnesses elevate low-level content to a higher
   instruction level via context construction. 13 attack objectives across
   6 coding-agent harnesses achieved 13/13 under unrestricted execution and
   13/13 under automatic permission review on the three harnesses that
   offer it. Direct motivation for `elevatescan`. The paper's methodology,
   subject harnesses, and any reference measurement code were NOT
   consulted.
   [arXiv](https://arxiv.org/abs/2608.27299)

2. **When Tool Outputs Become Commands: Separating Action Induction from
   Runtime Authorization in Tool-Augmented LLM Agents** (arXiv 2608.27146,
   2026-08-27). SARA separates action induction from execution
   authorization and No-History-Promotion prevents historical recurrence
   from laundering action origins into execution authority. Limits attack-
   success-rate to <=0.63% on AgentDojo and AgentDyn. Complementary framing
   to 2608.27299: 27299 is about harness-construction-time elevation, 27146
   is about runtime tool-output-surface elevation. Both signal that the
   pre-flight content surface (elevatescan's domain) is a first line of
   defense.
   [arXiv](https://arxiv.org/abs/2608.27146)

3. **LongPIBench: A Long-Context Benchmark for Prompt Injection** (arXiv
   2608.28411, 2026-08-28). 4 realistic scenarios (paper peer review,
   resume screening, code review, email summary), thousands to tens of
   thousands of tokens. Even simple heuristic injection shapes achieve
   high success and frequently bypass state-of-the-art defenses. Signals
   that pattern-heuristic detection at content-ingest time is not
   obsoleted by model-side defenses -- it is complementary.
   [arXiv](https://arxiv.org/abs/2608.28411)

4. **Fidelity Is Not Enough: Dispatch-Level Instrumentation for Agentic
   Datasheet Extraction** (arXiv 2608.28439, 2026-08-28). Two-rule
   silent-failure detector operates only on tool-call dispatch trace
   (never on the extracted value): raises no flag on 207 clean fidelity-
   passing extractions and recovers all 50 planted faults that withhold
   the tools the rules check. Signals a `dispatchcheck` primitive; deferred
   because the useful surface is a live tool-call log, not a static file.
   [arXiv](https://arxiv.org/abs/2608.28439)

5. **EvoUndo: Recoverability-Constrained Self-Evolution for LLM Agent
   Harnesses** (arXiv 2608.28363, 2026-08-28). 600 unseen one-shot
   self-evolution tasks; 197 capability-improving mutations fail
   recoverability verification. Conventional repair strategies recover
   0/197 under the original recovery representation; deterministic oracle
   with extended recovery calculus recovers 191/197. Signals a
   `reversibility-audit` primitive; deferred pending a static file surface.
   [arXiv](https://arxiv.org/abs/2608.28363)

6. **Post-Edit Re-Verification in Simulator-Backed Engineering Agents**
   (arXiv 2608.28147, 2026-08-28). Cadence-Guided vs Cadence-Omitted:
   re-verification 94/120 vs 32/120; cadence violations 26/120 vs 87/120;
   bounded final success 95/120 vs 35/120. Signals verification cadence as
   an explicit interaction-protocol component; too domain-specific for a
   small primitive.
   [arXiv](https://arxiv.org/abs/2608.28147)

7. **Persona-Execution Separation: An Architecture Pattern for Evolving LLM
   Agents under Execution Audit** (arXiv 2608.27427, 2026-08-27). Design
   pattern separating agent instructions from audited execution in
   governed environments. Architecture, not a small-primitive shape.
   [arXiv](https://arxiv.org/abs/2608.27427)

8. **On the Maintenance and Co-evolution of Agent Plugins** (arXiv
   2608.28497, 2026-08-28). Empirical study of agent-plugin marketplace
   repositories: feature-driven commits, co-evolution dynamics. Adjacent
   to the `agentmdlint` domain; no distinct small-primitive shape this
   week beyond what agentmdlint already covers.
   [arXiv](https://arxiv.org/abs/2608.28497)

9. **Five Primitives for Governing Autonomous AI Agents at Runtime** (arXiv
   2608.26696, 2026-08-27). Discovery, identity, governance, attestation,
   supply-chain primitives for runtime agent control. Framing document;
   too broad for a small tool this cycle.
   [arXiv](https://arxiv.org/abs/2608.26696)

10. **Layered LLM Defenses as an Ensemble: Access Tiers, Inference Cost,
    and the Measured Failure Correlation Between Defense Layers** (arXiv
    2608.28327, 2026-08-28). Positive failure correlation between defense
    layers means adding a second layer buys less than independence
    assumptions predict. Reinforces the case for orthogonal pre-flight
    checks (elevatescan is orthogonal to runtime authorization checks
    because it operates on different data at a different time).
    [arXiv](https://arxiv.org/abs/2608.28327)
