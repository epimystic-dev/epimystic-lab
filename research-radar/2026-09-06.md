## What we chose to build, and why

**One artifact this week**, holding the standing quality-over-quantity bar.
The batch contains `delegcheck` and nothing else.

**`delegcheck`** -- offline static linter for the JSON / JSONL
configuration files that a modern agent harness reads to decide who can
call which tool, with which credential, on whose behalf, and with which
trust boundary. Zero-dep Python stdlib, MIT.

The direct motivation is a three-paper convergence this week on the same
observation: the *runtime authorization layer* cannot compensate for a
delegation *configuration* whose credentials have no scope, whose tools
have no principal, whose delegation edges have no depth cap, and whose
authorization mode is "the model decides."

1. arXiv 2609.00267 ("Delegation Without Trust: An Empirical Gap Analysis
   of Identity, Authorization, and Runtime Governance in Multi-Agent LLM
   Systems", 2026-08-31) enumerates four canonical failure modes:
   confused-deputy over delegated credentials, token theft and replay,
   prompt-injection privilege escalation, and compromised sub-agents;
   reports that a default runtime modelling common practice (broad bearer
   credentials, authorization gated inside the model) fails all four
   threats across the multi-agent frameworks it surveys.
2. arXiv 2609.00595 ("SoK: When Safe Agents Fail Together: The Security of
   Multi Agent LLM Systems", 2026-09-01) systematises 197 works under an
   Adversary-Interaction-Risk framework and observes that "safe agents
   can fail together" when information, state, decisions, and authority
   cross principal boundaries without an execution-level view. The
   compositional-failure claim implies that per-agent local checks miss
   the trust-boundary-crossing shapes.
3. arXiv 2609.01222 ("What's in Your Agent's Context? Context Privilege
   Escalation Attacks against AI Agent Harness", 2026-09-01) analyses 12
   real-world coding-agent harnesses and names two attack categories:
   MessageRole-CPE (low-priv content is incorporated into a higher-
   privileged message role) and Cross-Scope-CPE (attacker-controlled
   content persists beyond its introduced scope). Both categories trace
   back to configuration-level weaknesses in how roles and credentials
   are declared.

`delegcheck` reads the configuration file the harness will consume and
flags ten shape defects before the harness loads it: unbounded credential
scope (DEL-001), tools without a principal identity field (DEL-002),
authorization gated inside the model (DEL-003), parent credentials reused
verbatim without scope narrowing (DEL-004), delegation edges without a
depth cap (DEL-005), tools exposed to wildcard callers (DEL-006), bearer
credentials without an expiry field (DEL-007), internal trust boundaries
claimed on cross-principal edges (DEL-008), delegation cycles (DEL-009),
and bearer literals embedded in the config file itself (DEL-010). Five
HIGH, four MEDIUM, one INFO. Verdict rollup, deterministic exit codes,
`--json` for CI, `--strict` / `--include-info` / `--disable RULE_ID`
per-repo overrides, exactly as in the other members of the lab's
hygiene-linter family.

170 tests: 12 types tests (Severity / Verdict enums + Finding immutability
+ sort-key ordering + ScanResult defaults), 21 parser-helper tests
(offset-to-line-col across LF / CRLF / negative / overflow, find_key with
from-offset, BOM stripping, JSON / JSONL loading, snippet truncation and
newline-flattening), 8 rule-registry invariants (count == 10 + id
uniqueness + canonical DEL-NNN + non-empty descriptions + valid
severities + expected 5/4/1 HIGH/MEDIUM/INFO split + check-fns callable),
per-rule positive+negative across all ten rules with adversarial-vs-clean
discrimination (7 for DEL-001, 6 for DEL-002, 6 for DEL-003, 5 for
DEL-004, 5 for DEL-005, 5 for DEL-006, 5 for DEL-007, 5 for DEL-008, 5
for DEL-009, 5 for DEL-010 plus a healthy-config-fires-nothing surface
check), 24 scanner tests (read_text utf-8 / BOM-strip / latin-1 fallback /
max-bytes cap; discover missing-path / single-file glob-match / miss / dir
walk / case-insensitive / max-files cap / deterministic sort / custom
glob / jsonl default; scan_file json healthy / json unhealthy / jsonl
per-line / invalid-json-no-crash / disable-suppresses; scan_path empty /
findings-sorted / disable-suppresses / max-files-bound), 17 verdict-and-
report tests (rollup no-files-unknown / high-unhealthy / medium-needs-
attention / high-beats-medium / info-default-healthy / info-strict-needs-
attention / no-findings-healthy; exit-codes 0/1/2 across verdicts; text
verdict-line + totals + hides-info-by-default + shows-info-with-include-
info + lists-errors; JSON parseable / deterministic / omits-info-by-
default / includes-info-when-configured / errors-field), 11 CLI tests
(--version / --list-rules / missing-path / healthy-dir / unhealthy-dir /
no-files-default / no-files-strict / --json / --include-info /
--disable-flips-verdict / --max-files-0 / --max-bytes-0 / default-path-is-
cwd / --glob-extends-default), and 14 end-to-end fixture tests across
the ten adversarial fixture shapes plus healthy + unknown + DEL-010
generated-at-runtime (secret-shaped fixtures are assembled from
sub-16-char parts, never a verbatim token in source) plus a JSON-
roundtrip determinism verification and a cross-fixture sort-order
invariant.

Dogfood: running `delegcheck examples/weak_delegation.json` yields
verdict=unhealthy, exit 2, 12 findings across 7 HIGH (DEL-001, DEL-002 x2,
DEL-005 x2, DEL-004, DEL-003) and 5 MEDIUM (DEL-007, DEL-006, DEL-009,
DEL-008 x2) -- proof that the primitive fires cleanly against a config
that stitches every high-severity defect and a delegation cycle into one
adversarial file. Same tool on `examples/healthy_delegation.json` yields
verdict=healthy, exit 0, zero findings.

The lab's hygiene-linter family already covers file-content hygiene
(`envcheck`, `jsonlcheck`, `jwtcheck`), eval-stream hygiene (`jsonldiff`,
`jsonlsample`), install-manifest hygiene (`reqcheck`), license-chain
hygiene (`licensechain`), contribution-policy hygiene (`aicontribcheck`),
agent-skill safety hygiene (`skillcheck`), agent-instruction
maintainability hygiene (`agentmdlint`), test-oracle-shape hygiene
(`oraclecheck`), and agent-consumed-content hygiene (`elevatescan`).
`delegcheck` adds the **agent-delegation configuration** layer:
`elevatescan` scans the content an agent will *ingest*; `delegcheck` scans
the config the harness will *load*. Two orthogonal surfaces of the same
runtime.

Secondary candidates considered this cycle: `contextaudit` from arXiv
2609.01222 itself (the paper's own detector for MessageRole-CPE and
Cross-Scope-CPE runtime traces -- deferred because the useful surface is
a live message transcript, not a static file); `safeguardeval` from arXiv
2609.00519 ("The Safeguard Worked. Is the LLM System Safer?" -- deferred
because it is a methodology paper, not a small-primitive shape);
`memorypoisonlint` from arXiv 2609.00523 (transferable indirect long-term
memory poisoning -- deferred because static-config surface would be too
narrow relative to a runtime memory dump).

## Signal we noted (not built this week)

1. **Delegation Without Trust: An Empirical Gap Analysis of Identity,
   Authorization, and Runtime Governance in Multi-Agent LLM Systems**
   (arXiv 2609.00267, 2026-08-31). Enumerates four canonical failure
   modes (confused-deputy, token theft, prompt-injection privilege
   escalation, compromised sub-agents) and reports that a default runtime
   modelling common practice fails all four threats. Direct motivation
   for `delegcheck`. The paper's methodology, subject frameworks, and
   any reference measurement code were NOT consulted.
   [arXiv](https://arxiv.org/abs/2609.00267)

2. **SoK: When Safe Agents Fail Together: The Security of Multi Agent LLM
   Systems** (arXiv 2609.00595, 2026-09-01). Systematises 197 works
   under an Adversary-Interaction-Risk framework and observes that safe
   agents fail together when authority crosses principal boundaries
   without an execution-level view. Motivates DEL-008 (internal
   boundary on cross-principal delegation) and DEL-009 (delegation
   cycle).
   [arXiv](https://arxiv.org/abs/2609.00595)

3. **What's in Your Agent's Context? Context Privilege Escalation Attacks
   against AI Agent Harness** (arXiv 2609.01222, 2026-09-01). Analyses
   12 real-world harnesses and names MessageRole-CPE and Cross-Scope-CPE
   as attack categories. Motivates DEL-002 (missing principal) and
   DEL-003 (authorization gated inside the model) as configuration-level
   root causes.
   [arXiv](https://arxiv.org/abs/2609.01222)

4. **Will the User Ever Know? Covert Indirect Prompt Injection Attacks on
   Tool-Using LLM Agents** (arXiv 2608.30362, 2026-08-31, v2
   2026-09-01). Introduces Induced Covert Attack (ICoA), which steers
   agents back to the user task after executing the injection so no
   trace appears in the final response. Reports gains of 3.79-12.01
   percentage points in covert success rate over the strongest baseline
   on AgentDojo. Signals a runtime-detection surface (transcript
   post-processing for return-to-task control transitions); deferred
   because that surface is not static-file.
   [arXiv](https://arxiv.org/abs/2608.30362)

5. **The Safeguard Worked. Is the LLM System Safer?** (arXiv 2609.00519,
   2026-09-01). Evaluates whether an individual safeguard translates
   into system-level safety improvement -- a methodology paper. Not a
   small-primitive shape; noted as a framing reinforcement that
   orthogonal pre-flight checks like `elevatescan` and `delegcheck` are
   complementary rather than duplicative of runtime safeguards.
   [arXiv](https://arxiv.org/abs/2609.00519)

6. **Transferable End-to-End Optimization for Indirect Long-Term Memory
   Poisoning** (arXiv 2609.00523, 2026-09-01). Attack method targeting
   agent memory persistence across sessions. Runtime memory dumps would
   be the natural detection surface; deferred pending a static-file
   equivalent.
   [arXiv](https://arxiv.org/abs/2609.00523)

7. **AgentProv: Auditing LLM API Providers through Tool-Use Policy
   Probes** (arXiv 2609.00052, 2026-09-01). Provider-side authorization-
   gap detection via probes. Live-probe methodology; not a small-file
   surface.
   [arXiv](https://arxiv.org/abs/2609.00052)

8. **HiveTraceGuard-Pro** (arXiv 2609.01046, 2026-09-01). Compact
   guardrail defending against prompt injection and jailbreaks via
   generative filtering. Runtime component; framing signal that guard
   layers are proliferating and pre-flight primitives (this week's
   delegcheck; last week's elevatescan) remain complementary.
   [arXiv](https://arxiv.org/abs/2609.01046)

9. **When Safety Routing Breaks** (arXiv 2609.01455, 2026-09-01). Fine-
   tuning fragments alignment safeguard mechanisms. Fine-tuning-time
   surface; adjacent to `oraclecheck` / `agentmdlint` scope but no
   distinct small-primitive shape this week.
   [arXiv](https://arxiv.org/abs/2609.01455)

10. **Context Inference Attacks Without Jailbreaks** (arXiv 2609.01663,
    2026-09-01). Extracts agent context through inference patterns
    without overt exploitation. Runtime observation surface; deferred.
    [arXiv](https://arxiv.org/abs/2609.01663)

11. **Hacker News community signal** -- MCP-server security tooling
    threads continue at a steady cadence (MCP Security Auditor, Snyk's
    MCP-aware AI-agent scanner, Canopii deterministic MCP scanner,
    HoneyMCP defensive deception layer). Independent confirmation that
    the MCP-descriptor / agent-delegation-config surface is a live
    community need. `delegcheck` complements those tools by targeting
    the delegation-graph and credential-shape defects specifically,
    rather than the server implementation.
